# Security Policy

## Supported Versions

|     Version     |     Supported      |
| :-------------: | :----------------: |
| Versioned tags  | :white_check_mark: |
| `master` branch | :white_check_mark: |
| Other branches  |        :x:         |

## Reporting a Vulnerability

To report a vulnerability, please submit a draft security advisory [here](https://github.com/Amia33/nextjs-fuwari/security/advisories/new). I will reply within a week after submitting.
